Discord draft review — live AG-UI over SSE, rendered by AILANG in your browser

POSTs a RunAgentInput to /run; the server runs the AILANG serve step and streams AG-UI events back. The stream is rendered by an AILANG module (renderer.ail) executed in this page through the AILANG WASM runtime, with a JavaScript fallback if WASM is unavailable. The action button posts the A2UI draft-review action back to /action. Offline by design: the run stores a draft; the action decides whether it sends.
