Instinct, with evidence.
Things in this world have descriptions, not “edible” or “dangerous” flags. In live mode, a decision model reads a creature’s perception and answers typed questions with probabilities.
AILANG checks threats and the creature’s confidence threshold, then samples an action. The full decision and random roll are saved so that the action can be reproduced offline.
The habitat runs in your browser. New judgments run through Jev via the Studio. You can inspect or replay a saved decision from the ledger without making another model call.


Give them intuition.
Live mode sends your key and creature perceptions to this private Studio preview server over HTTPS. The server runs the AILANG decision call through OpenRouter to TypeSafe.
The key is saved in this browser and used only in memory on the Studio for each request. It is not written to a server file. Live calls incur usage charges. The world keeps making decisions until you pause it. Recorded cost is shown below the habitat.
If browser networking is unavailable, record with the CLI and import the bank here.

Jev’s interpretation
Confidence and threat settings guide its choices; urgency can override caution. Speed and stamina change its movement and tiredness.
All Nouls can walk, investigate, eat, drink, poo, rest and flee. Flying, magic, combat and crafting remain description only. Appearance uses one of our four existing creatures.
Inspect the mapping evidence
Numeric traits use the expected value of Jev’s full score distributions. Appearance uses its highest-ranked choice. Actions in the habitat are still sampled.
