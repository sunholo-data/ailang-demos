Discord draft review — the whole agent run is AILANG, including the part in your browser

The server side decodes the client's request with the published sunholo/agui packages, runs an agent step, and streams AG-UI events. This page replays a recorded run, and the rendering is not JavaScript: an AILANG module (renderer.ail) is executed by the AILANG WASM compiler runtime right here in your browser, one event at a time. The same language, the same module format, both sides of the wire.

loading the AILANG WASM runtime…

The replay is a completed run: it read the channel fixture, drafted a reply and published an A2UI review surface. In the live deployment this page is served by the agent's own SSE server: the request is a real RunAgentInput, the draft is created from your text, and the review card's button posts the action back — with the policy gate deciding whether it sends to the #daneel channel on the sunholo Discord server. The static page keeps the send safely off; the live one can flip it on.
