The code

-- linkedin/services/linkedin_posts.ail:32
export func linkedinCreatePost(token: string, orgUrn: string, text: string)
  -> Result[PostResult, string] ! {Net @limit=1}
requires { length(text) > 0 && length(text) <= 3000 }
{
  let url = "https://api.linkedin.com/rest/posts";
  let body = encode(jo([
    kv("author", js(orgUrn)),
    kv("commentary", js(text)),
    kv("visibility", js("PUBLIC")),
    ...
  ]));
  match httpRequest("POST", url, linkedinHeaders(token), body) { ... }
}

The requires clause — "text length between 1 and 3000" — is checked by the compiler. The Net @limit=1 means this function can make at most one network call, ever. Both are mathematical, not advisory.
