What the compiler enforces

None of these are policies that hold if a reviewer remembers. Each is a language feature that refuses to compile when we slip up.

string<pii> ⟶ ! {Declassify}

Information-flow labels keep your LinkedIn identity private.

The LinkedInComment type marks authorName and text as string<pii>. To produce a public version they must pass through linkedinSanitiseComment, whose signature carries ! {Declassify}. That function SHA-256s the actor URN into initials + a six-hex seed. Any code that publishes the raw fields doesn't compile.

IFC labels guide ↗
! {Net, FS, AI, IO}

Effect rows make every side effect visible in the signature.

Each function names what it touches. The dispatcher that publishes a sketch has ! {Net, FS, AI, IO} in its type — anything not listed there is unreachable from this code path. Reviewer attention not required.

Effects intro ↗
Net @limit=1, AI @limit=50

Capability budgets cap each run at a known number of calls.

The comment-fetch is Net @limit=1 — at most one HTTPS request per run, enforced by the runtime. No retry loops, no telemetry, no surprise outbound traffic. The sketch generator's AI budget is similarly bounded.

Parameterised effects ↗
requires { len(text) ≤ 3000 }

Contracts are Z3-verified, not runtime checks.

LinkedIn's 3000-character post limit is a requires clause on linkedinCreatePost, proved by an SMT solver. The rubric scorer's points-clamping is a contract too. Violations don't ship — they don't compile.

Contracts & verification ↗
! {AI}

The AI effect is typed, budgeted, and stubbable.

The Gemini call that extracts your site is a first-class effect, not a HTTP wrapper. It carries a per-run budget, can be deterministic-stubbed in tests, and appears in every caller's signature. Nothing in the rendering path can sneak in a second model call.

AI effect guide ↗
type Topic = Privacy | Portable | AgentReady

Closed sum types make exhaustive handling a compile error.

Topics are a closed ADT. Adding a fourth without handling it in the scorer, the renderer, and the leaderboard is a compile-time error — there's no quiet "unknown topic" fallback that could drop a sketch on the floor.
